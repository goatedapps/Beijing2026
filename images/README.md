# Images

Drop your own photos into this folder using the exact filenames below. Until a file exists, the itinerary page shows a placeholder card in its place — no code changes needed once the file is added.

| Filename | Used for |
|---|---|
| `airport-pek.png` | Day 1 — Arrival, Beijing Capital Airport (PEK) |
| `hotel-sunworld-dynasty.png` | Sunworld Dynasty Hotel — used every time the itinerary departs from or returns to the hotel (Days 1–6) |
| `wudaoying-hutong.png` | Day 1 — Wudaoying Hutong & Café Hopping |
| `forbidden-city.png` | Day 2 — The Forbidden City |
| `jingshan-park.png` | Day 2 — Jingshan Park |
| `nanluoguxiang-hutong.png` | Day 2 — Nanluoguxiang Hutong |
| `shichahai-lakes.png` | Day 2 — Shichahai Lakes |
| `mutianyu-great-wall.png` | Day 3 — Mutianyu Great Wall |
| `temple-of-heaven.png` | Day 4 — Temple of Heaven |
| `798-art-district.png` | Day 4 — 798 Art District |
| `beijing-imperial-banquet.png` | Day 4 — Beijing Imperial Banquet |
| `summer-palace.png` | Day 5 — The Summer Palace |
| `qianmen-street.png` | Day 5 — Qianmen Street & Dashilan |
| `airport-pkx.png` | Day 6 — Departure, Beijing Daxing International Airport (PKX) |

Any common image format works (`.jpg`, `.png`, `.webp`, etc.) — just update the `src` path in the `photo` field for that stop in `index.html` if you use a different extension.
